Qui trovi, in parole semplici, **perché ogni task richiede ancora Codex e se conviene lanciarlo come Prompt normale oppure Goal**. Tutto ciò che è eseguibile direttamente sui repository remoti resta fuori dalla coda Codex.

L'ordine è ottimizzato per evitare lavoro duplicato: prima il piccolo deploy del monitor, poi il backend Datasette; prima di proseguire col Data Explorer Android viene chiuso il gate locale ad alto rischio del nuovo Git Data/History, quindi si completa Datasette Lite e infine si valida la build Play risultante. Le attività indipendenti restano in coda senza spezzare questa dipendenza.
